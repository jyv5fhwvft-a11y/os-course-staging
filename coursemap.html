The Five Paradigm Lens
Every lecture compares how different kernel architectures handle the topic. The five paradigms are the analytical framework of the entire course.

Monolithic

All subsystems in Ring 0, direct function calls. Fastest, most fragile.

Linux · FreeBSD · OpenBSD

Microkernel

Minimal Ring 0 core, user-space servers via IPC. Strongest isolation, slower.

seL4 · MINIX 3 · QNX · EROS

Layered

Strict vertical hierarchy — layer N may only call layer N-1. Elegant but rigid.

THE Multiprogramming System

Modular

Monolithic core + hot-swappable loadable modules. Fast and extensible.

Linux LKMs · FreeBSD · NetBSD

Hybrid

Critical code in Ring 0, risky subsystems in Ring 3. The modern pragmatic standard.

Windows NT · macOS XNU · Android
Three Recurring Tensions
Every subsystem resolves these three tensions differently. Understanding them is the deepest insight of the course.

⚖️ Isolation vs. Sharing

  • Ring 0 / Ring 3 barrier (L02)
  • Paging — shared frames (L11)
  • ACLs — protected resources (L22)
  • Containers — isolated workloads (L27)

⚡ Speed vs. Safety

  • TLB caching (L12)
  • Journaling — ordered vs. journal (L19)
  • C vs. Rust memory safety (L24)
  • Containers vs. VMs (L27)

🔧 Simplicity vs. Flexibility

  • Monolithic vs. microkernel (L01)
  • Flat vs. hierarchical FS (L17)
  • Char vs. block devices (L21)
  • ACLs vs. capabilities (L22)
